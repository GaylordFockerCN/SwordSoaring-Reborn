## 🌟 中文介绍  

### 项目定位
**《御剑凌虚》** 是 [Epic Fight Mod](https://www.curseforge.com/minecraft/mc-mods/epic-fight-mod) 的附属模组，完整实现了：
- ✅ 多种御剑技能
- ✅ 时装工坊适配
- ✅ 全新武器卫国者
- 🚧 全新ef boss开发中...

### ✨ 功能亮点
| 模块    | 功能描述                                   |
|-------|----------------------------------------|
| 剑诀系统  | 实现御剑飞行、王之宝库、万剑归宗等多种技能，并且所有武器都可以使用      |
| 自定义实体 | 所有剑诀系统生成的剑的实体皆为ef实体，通过blender动画控制其运动轨迹 |
| 语言翻译  | 支持en_us、 zh_cn 以及最重要的 lzh              |
| 适配性   | 所有技能的武器都可以使用时装工坊的模型，也适配主流替换模型的模组       |
| 扩展    | 提供了海量的原创动画，它们大部分可以直接使用                 |

## 🌟 English Introduction

### Project Vision
**《Sword Soaring》** is an add-on mod for [Epic Fight Mod](https://www.curseforge.com/minecraft/mc-mods/epic-fight-mod), featuring:
- ✅ Multiple sword skills
- ✅ Custom weapon skins support
- ✅ New weapon: "Guardian of the Nation"
- 🚧 New Epic Fight boss in development...

### ✨ Key Features
| Module       | Description                                                                 |
|--------------|-----------------------------------------------------------------------------|
| Sword Skills | Implements various skills like aerial dash, Gate of Babylon, and Sword Rain, usable with all weapons |
| Custom Entities | All sword entities generated by skills are Epic Fight entities, with motion controlled by Blender animations |
| Language Support | Supports en_us, zh_cn, and most importantly, lzh (Literary Chinese) |
| Compatibility | All skill weapons support custom skins and are compatible with major model-replacement mods |
| Extensions   | Provides a vast library of original animations, most of which can be used directly |
